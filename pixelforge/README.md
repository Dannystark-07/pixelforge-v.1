# PixelForge

PixelForge is a tiny browser-based pixel art editor built with plain HTML, CSS, and JavaScript.

## Features

- Paint and erase on a configurable grid
- Palette color picker
- Clear canvas action
- Download sprite as a PNG image
- Responsive layout for desktop and mobile browsing

## Run locally

From this folder, start a simple local web server:

```bash
python3 -m http.server 3000
```

Then open http://localhost:3000 in your browser.

## Files

- index.html — app structure
- styles.css — visual design and layout
- script.js — drawing logic and export features
