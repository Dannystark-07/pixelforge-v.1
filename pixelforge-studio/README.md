# Pixelforge Studio

Pixelforge Studio is a browser-based design editor inspired by Canva and Photoshop, built with plain HTML, CSS, and JavaScript.

## Features

- Select, drag, resize, and delete objects
- Add rectangles, ellipses, text, and images
- Upload your own images
- Adjust properties like position, size, opacity, fill, and filters
- Duplicate and layer ordering controls
- Export the final composition as a PNG
- Undo/redo history
- Zoom in and out on the canvas

## Run locally

```bash
cd /workspaces/pixelforge-v.1/pixelforge-studio
python3 -m http.server 3001
```

Then open http://localhost:3001

## Notes

This project is structured as a lightweight editor for learning and rapid prototyping. It is designed to be easy to extend for more advanced design features.
